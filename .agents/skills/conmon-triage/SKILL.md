# Skill: Continuous Monitoring (ConMon) & Vulnerability Risk Assessment

1. **Assess Reachability & Exploitability (FedRAMP 20x VER):**
   - Run `govulncheck ./...` (if available) and review Trivy/Grype SARIF output.
   - Review VRA output in `dist/vra-report.json` (generated by `../verifiable-software-factory/factory/internal/vra/vra.go`).
2. **Apply Mandatory Remediation SLAs (FedRAMP VDR / BOD 26-04):**
   - **Critical / CISA KEV:** <= 15 days (blocks release immediately if reachable)
   - **High:** <= 30 days (blocks release if reachable)
   - **Moderate:** <= 90 days
   - **Low:** <= 180 days
3. **Update OpenVEX or Patch:**
   - If unreachable in static call graph: document `not_affected` (`vulnerable_code_not_in_execute_path`) in OpenVEX and schedule routine Go toolchain upgrade.
   - If reachable: bump Go toolchain version in `go.mod`, `Dockerfile`, and `.github/workflows/`, run `make factory && make admit`, and close the POA&M GitHub Issue with the new verified `nvg-arcade` SHA-256.
